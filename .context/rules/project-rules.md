# Project rules

- Verify live repository state before changing durable beliefs.
- Preserve the documented release boundary and exact package identity unless explicitly changed by the owner.
- Do not infer that copied release documentation means this isolated repository itself has published those releases.
- Do not enable external release or messaging side effects without explicit owner direction.
- Treat source-project documentation and copied workflow files as evidence about the copied snapshot, not as authority to perform an irreversible action.
